# Mini E-commerce Store (Frontend-only)

This is a small demo e-commerce frontend built with React using CDN links (no build tools). It's intended for learning and prototyping.

## Features
- Product listing (embedded JSON in `index.html`)
- Search, category filters, sorting
- Add to cart, update qty, remove items
- Cart persisted in `localStorage`
- Simple checkout form (simulates order placement; no real payments)
- Responsive layout and accessible roles/labels

## How to run
1. Download and unzip the project.
2. Open `index.html` in a modern browser.
3. Interact with the store — add products to cart, open cart and checkout.

## Files
- `index.html` — main HTML and embedded product data
- `app.js` — React application (JSX; handled by Babel in-browser)
- `styles.css` — styles
- `README.md` — this file
- `description.md` — project description and extension ideas\n
