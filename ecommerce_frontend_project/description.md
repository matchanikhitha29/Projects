Project Description & Possible Extensions

Description:
This mini e-commerce frontend demonstrates core UI and state patterns common to online stores:
- Product browsing with search and filters
- Cart management with quantities and subtotal calculation
- Persists cart in localStorage so user state survives reloads
- Basic checkout flow (form validation + simulated order creation)

Possible extensions you can add:
- Product details page (routing) and image galleries
- Integrate with a backend API for products and orders (Node/Express, Firebase)
- Implement user authentication (signup/login) with JWT or Firebase Auth
- Add payment integration (Stripe / Razorpay) for real transactions
- Improve accessibility and keyboard navigation
- Add sorting by more fields, product reviews, and inventory checks

Who is this for:
- Beginners learning React state and UI patterns
- Bootcamp projects or portfolio sample (replace placeholder images & product data with real assets)\n
