# React Todo & Notes App (No Build)

This is a small frontend project that demonstrates a todo/notes application built with **React** using CDN links (no build tools required). You can run it by opening `index.html` in a modern browser.

## Features
- Add notes with title and body
- Edit, delete notes
- Mark notes as done / undo
- Search notes and filter (All / Active / Done)
- Persist data in `localStorage`
- Accessible and responsive layout

## How to run
1. Download and unzip the project.
2. Open `index.html` in your browser.
3. Start using the app. Data is stored in your browser's localStorage.

## Files
- `index.html` – main HTML file, includes React/ReactDOM/Babel from CDN
- `app.js` – application logic (JSX handled by Babel in-browser)
- `styles.css` – simple styles
- `README.md` – this file
- `description.md` – project description and learning notes\n
