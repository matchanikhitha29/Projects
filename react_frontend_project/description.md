Project Description & Learning Notes

This small project is designed as a beginner-friendly frontend assignment:
- Focuses on React fundamentals: components, state, effects, mapping lists.
- Demonstrates an approach to persist data (localStorage) for small apps.
- Uses React via CDN to avoid build tool complexity: good for quick demos or learning.
- Accessibility considerations: role attributes, aria-live, button labels.
- Responsive layout: adapts for small screens with simple CSS media queries.

Possible extensions:
- Add categories or tags
- Sync to a backend (Firebase / Node + DB)
- Add sorting, drag-and-drop reordering
- Add user authentication
- Replace in-browser Babel + CDN with a proper React toolchain (Vite / Create React App)\n
